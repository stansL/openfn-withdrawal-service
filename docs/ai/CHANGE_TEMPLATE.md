# Change and review template

Use this in the task response or a task-specific record; do not overwrite the historical PLAN.md. Follow [CHANGE_PROTOCOL.md](CHANGE_PROTOCOL.md). Keep documentation-only plans brief.

## Before editing

- Requested outcome and authorization scope:
- Execution path, state owner and direct/transitive callers:
- Intended files and existing edits to preserve:
- Affected invariants, API/data contracts and compatibility:
- Targeted tests/documentation checks and full verification:
- Risks, exclusions and decisions needed:
- Git baseline or saved-original location:

## Handover

- Result and reviewed files:
- Exact verification commands, outcomes and skipped tests:
- Review type (self/independent), reviewer and reviewed revision/diff:
- Findings, severity, evidence, resolution and remaining limitations:
- Each of the nine AGENTS.md invariants: pass/fail with test or inspection evidence:
- Material decision/review-log updates, if any:
- Staging status and pre-existing staged work:
- Human gate: stopped pending explicit approval; state any requested next action.

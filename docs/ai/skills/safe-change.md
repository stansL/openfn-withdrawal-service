# Prompt: Safe change

Follow [the change protocol](../CHANGE_PROTOCOL.md), including its authorization rules. Implement the stated narrow plan within the engineer's request. Preserve unrelated behavior, interfaces and existing edits. Add/update meaningful regression tests for changed behavior/invariants and run affected caller/contract/persistence tests. Run full verification, review and stage only as the protocol permits; then stop at the human gate. Do not commit automatically.
